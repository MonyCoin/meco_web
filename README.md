# MECO Web

الموقع الرسمي الموحد لمنظومة **MECO Network**: رمز رقمي، محفظة عربية لا مركزية وتجربة Web3 على شبكة Solana.

## المنتجات الرسمية

| المنتج | الرابط | الوظيفة |
|:---|:---|:---|
| 🪙 MECO Token | [meco-token](https://github.com/MonyCoin/meco-token) · [الموقع](https://monycoin.github.io/meco-token/) | الرمز، التوكنوميكس، المحافظ والشفافية |
| 📱 MECO Wallet | [meco_wallet](https://github.com/MonyCoin/meco_wallet) · [صفحة المحفظة](https://monycoin.github.io/meco_web/wallet.html) · [التحميل](https://monycoin.github.io/meco_wallet-app/) | إدارة الأصول والسيولة والتخزين السائل وWeb3 على Solana |
| 🌐 MECO Web | [الموقع الرسمي](https://monycoin.github.io/meco_web/) | البوابة الموحدة للمنظومة |

## البيانات الرسمية

- **الشبكة:** Solana Mainnet-Beta
- **المعيار:** SPL Token
- **العقد:** [`A5Ln25cfww33kfUSzBb89bMha7j1PnFQTy7H3FsQHN7W`](https://solscan.io/token/A5Ln25cfww33kfUSzBb89bMha7j1PnFQTy7H3FsQHN7W)
- **المعروض:** 1,000,000,000 MECO
- **التوكنوميكس:** 50% سيولة، 20% تطوير، 10% خزينة، 10% فريق، 10% مجتمع
- **إصدار المحفظة الحالي:** يُجلب تلقائياً من آخر Release على GitHub (لا يُكتب يدوياً في الصفحات)

## بنية الصفحات

- **الرئيسية:** تقديم MECO Network وربط المنتجات الرسمية.
- **MECO Token:** البيانات الفنية والتوكنوميكس والشفافية.
- **MECO Wallet:** الميزات والأمان والرسوم وروابط التحميل.
- **عن المشروع:** المؤسسة والرؤية والعلاقة بين الرمز والمحفظة.
- **خارطة الطريق:** مراحل التأسيس والإطلاق والنمو والتوسع.
- **المدونة:** أخبار وتحديثات قابلة للتحقق (المقالات القديمة أرشيف وتحمل تنبيهاً عند الحاجة).
- **تواصل معنا:** قنوات المجتمع والدعم.

## نظام التصميم والتفاعل

- هوية موحدة باسم `MECO Network` وألوان أرجوانية/سماوية مشتركة.
- دعم العربية واتجاه RTL، مع مظهر داكن وفاتح محفوظ محلياً.
- هيدر وفوتر متجاوبان وقائمة هاتف موحدة.
- روابط خارجية آمنة وتحسينات `focus-visible` و`prefers-reduced-motion`.
- ملف التصميم المشترك: `styles.css`.
- السلوك العام المشترك: `app.js` (المظهر، القائمة، رقم الإصدار الحي).

## قواعد المحتوى

- لا تُكتب نسب عوائد أو وعود أرباح؛ العائد من رسوم التداول الفعلية أو من خدمات خارجية وغير مضمون.
- رسوم الخدمة الحالية (0.0005 SOL) معلنة في صفحة المحفظة وشروط الاستخدام؛ عند تغييرها تُحدَّث الصفحتان وسياسة الخصوصية إن لزم.
- الأرقام والميزات يجب أن تطابق التطبيق المنشور.

## التشغيل محلياً

```bash
git clone https://github.com/MonyCoin/meco_web.git
cd meco_web
python3 -m http.server 8080
```
