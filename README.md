# MECO Web

الموقع الرسمي الموحد لمنظومة **MECO**: رمز رقمي ومحفظة عربية لا مركزية وتجربة Web3 على شبكة Solana.

## الهوية الموحدة

- **MECO Token:** [MonyCoin/meco-token](https://github.com/MonyCoin/meco-token)
- **MECO Wallet:** [MonyCoin/meco_wallet](https://github.com/MonyCoin/meco_wallet)
- **الموقع الرسمي:** https://monycoin.github.io/meco_web/
- **العقد:** [`A5Ln25cfww33kfUSzBb89bMha7j1PnFQTy7H3FsQHN7W`](https://solscan.io/token/A5Ln25cfww33kfUSzBb89bMha7j1PnFQTy7H3FsQHN7W)

## بنية الموقع

| القسم | الغرض |
|:---|:---|
| الرئيسية | تقديم منظومة MECO وروابط المنتجات الرسمية |
| MECO Token | البيانات الفنية، التوكنوميكس، المحافظ والشفافية |
| MECO Wallet | ميزات المحفظة، الأمان وروابط التحميل |
| عن المشروع | الرؤية والمؤسسة والمنظومة |
| خارطة الطريق | مراحل التنفيذ والنمو |
| المدونة | الأخبار والإعلانات والتحديثات |
| تواصل معنا | قنوات المجتمع والدعم |

## المظهر والتفاعل

- هوية بصرية موحدة تعتمد على `MECO Network`.
- دعم كامل للعربية واتجاه RTL.
- مظهر داكن وفاتح محفوظ في `localStorage`.
- قائمة متجاوبة للجوال.
- روابط خارجية آمنة باستخدام `noopener noreferrer`.
- دعم `prefers-reduced-motion` وتحسينات الوصولية.

## التشغيل محلياً

```bash
git clone https://github.com/MonyCoin/meco_web.git
cd meco_web
```

يمكن فتح `index.html` مباشرة، أو تشغيل خادم ملفات ثابتة محلياً:

```bash
python3 -m http.server 8080
```

ثم افتح: http://localhost:8080
